# CandleC

CandleC is a CASM compiler and linker.

It is part of the **Candle ecosystem**, providing compilation and linking for **CASM**, targeting the CandleVM bytecode format.

## Documentation

For more information, architecture details, and usage instructions, visit
the [CandleC documentation](https://candle.nozyx.dev/docs/1/candlec).
